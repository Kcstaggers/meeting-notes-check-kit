# Try a pair and report what happened

Use the live exercise, check an action list, then open the paired case. If you try a model extraction, record the model/version, prompt and any manual mapping.

Open a trial-feedback issue with case IDs, your expected result, the observed result and what you would change. Tell us whether you used it in teaching or a workflow, or only explored it. Disagreement is useful. Do not post confidential meetings, personal contact details, employer material or customer data.

A trial report is not a testimonial or endorsement. If you propose a correction, point to the relevant fictional lines. Code changes should pass `npm test` and `npm run validate`. Changes to cases must regenerate the data copies with `npm run prepare-data`.
